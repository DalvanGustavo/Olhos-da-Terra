## 📖 Descrição

O projeto **Olhos da Terra** explora técnicas de **Visão Computacional** integradas a sensores e interfaces multimídia, permitindo a criação de experiências artísticas interativas em salas temáticas. O sistema interpreta estímulos visuais do ambiente e responde de forma dinâmica, ampliando a relação entre arte, tecnologia e espaço físico.

---

## 🎯 Objetivos

- Desenvolver um sistema de visão computacional em tempo real  
- Integrar sensores e processamento visual em uma instalação artística  
- Permitir interações imersivas entre público e ambiente  
- Servir como base experimental para projetos de arte tecnológica  

---

## 🚀 Funcionalidades

✔️ Captura de imagens e/ou vídeo  
✔️ Processamento visual em tempo real  
✔️ Integração com sensores externos  
✔️ Interface web para visualização ou controle  
✔️ Estrutura modular e expansível  

---

## 🛠️ Tecnologias

- **Python** – processamento de visão computacional  
- **JavaScript** – interatividade e integração  
- **HTML / CSS** – interface visual  
- **OpenCV** – processamento de imagens  
- Outros módulos conforme a necessidade do projeto

## 🧩 Como usar

Clone o repositório:

```bash
git clone https://github.com/DalvanGustavo/Olhos-da-Terra.git
cd Olhos-da-Terra
```

Ative um ambiente virtual (opcional):

```bash
python -m venv venv
source venv/bin/activate
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute o projeto principal (exemplo):

```bash
python main.py
```

> Ajuste os comandos conforme a estrutura real do projeto.
